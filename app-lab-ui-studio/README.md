# App Lab UI Studio — 3 weeks

Open `index.html` first. It connects the class launch kit, student magazine, teacher plan, build cards, and portfolio setup in one place.

**Teaching today:** open `Wednesday Nov 11/OPEN-FIRST.txt`, then `Wednesday Nov 11/Teacher-Run-Sheet.html`. Print the one-page `Student-App-Lab-Passport.pdf`. The first 90 minutes use three blank-screen apps and finish with a live Name Badge minor grade. The optional portfolio package is for later setup; it is not required for today's lesson.

**Student reading:** open `The-App-Lab-Field-Guide.html`. It is an 18-chapter, student-facing magazine with a visual menu of all 54 concepts, linked build maps, small lessons, tests, vocabulary, real-world connections, and both major assessment criteria. Keep the `magazine-assets/` folder beside it so its fonts load.

Open `App-Lab-UI-Studio.html` in a browser. It contains the six-class sequence, 18 detailed 30-minute cycles, toolbox map, assessment criteria, vocabulary, and searchable bank of 54 mini-app concepts. `Student-Mini-App-Cards.html` is a print-friendly set of 18 student build cards. The `sketches/` folder holds 57 screen-fit 1920×1080 SVG build maps: one for each screen, with two copies of the 320×450 App Lab UI at exact 1.5× scale, input/output arrows, and a color-coded property list. Three two-screen concepts each have two files.

`teacher-code/` has one annotated reference JavaScript file per scheduled cycle. Create the listed Design Mode elements with the exact IDs before pasting code. Paste into App Lab text mode, switch to Blocks, run the app, and save a student remix. For a student challenge, remove only the named UI Controls blocks from a working copy after you verify the complete version. Leave other logic in place.

The files passed local syntax, structure, mock behavior, and visual checks. Live App Lab conversion, asset selection, photo permissions, chart and canvas rendering must be verified in the teacher account. The chart's Data block can be built directly in Blocks mode if the provided array literal does not convert.
See `QA-RESULTS.md` for the exact checks and live-account limits.

`Wednesday Nov 11/Portfolio Apps Script/` is a teacher-owned Apps Script web-app portfolio with 54 app slots per student. New Google Sites pages cannot be created through Google's deprecated Sites API; `SETUP.md` explains the functional web-app alternative and the optional manual Sites embed. Deploying it requires teacher Classroom authorization and a real school-account test.

All sketches are instructional wireframes, not screenshots of Code.org.
