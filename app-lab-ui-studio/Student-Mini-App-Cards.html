Week 1 • Class 1 · mini app 01

Button Beacon

A one-tap status message for a busy room

30 MINUTES

1 · Build the screen

Use Design Mode. Place: Button, Label.

Exact IDs: screenMain · labelTitle · buttonAction · labelMessage

Starting properties: Start labelMessage with “Ready when you are.” Button text: “Tap for help.”

2 · Connect the behavior

In Blocks mode, use these UI Controls: onEvent, setText. Your teacher provides the other code.

Drag a label and button; name them labelMessage and buttonAction; place one onEvent click block and one setText block; run and tap.

3 · Prove it works

Before the tap the label says Ready; after the tap it says Help is on the way.

Explain: Which action or value is the input? What does the user see or hear as output?

Open screen 1 at full size
Core finish: If the screen is blank, students only need the button, label, and one working response.
If time: Change the message for a second audience.
